# Projeto de Inteligência Artificial I

Projeto desenvolvido pelo Grupo 02 Laboral para a Unidade Curricular de Inteligência Artificial I da Universidade Eduardo Mondlane (UEM), Faculdade de Engenharia.

## Objetivo

Implementar e avaliar as heurísticas h0, h1 e h2 para o problema de reordenação de contentores no Porto de Maputo. O projeto também inclui o cálculo do factor de ramificação efectivo b* e testes automatizados para validar os resultados.

## Testes

Com o Python instalado, execute os testes a partir da pasta do projeto:

```bash
python -m pytest
```
